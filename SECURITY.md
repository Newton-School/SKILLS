# Security Policy

## Reporting a vulnerability

**Do not open a public issue.** If you find a security problem in any skill in this repository — leaked credentials, an unsafe script, or anything else that could put users or contributors at risk — report it privately.

To report:

1. Go to the [Security tab](https://github.com/Newton-School/SKILLS/security) of this repository.
2. Click **"Report a vulnerability"**.
3. Fill in the form. Please include enough detail to reproduce the issue (path to the skill, what's wrong, suggested fix if any).

You'll get an acknowledgement within **5 business days**. We'll keep the report private until a fix is in place.

## Scope

This policy covers content in this repository — skill scripts, examples, and documentation. Vulnerabilities in third-party tools that a skill happens to use should be reported to those projects directly.

## Note

Private vulnerability reporting must be enabled by repo maintainers for the link above to work. If it's not yet enabled, please contact a maintainer through GitHub directly.
