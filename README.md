# SKILLS

An open-source collection of skills shared by the Newton School community.

This repository is a home for reusable skills people have built and want to share — organized by domain so anyone can browse, learn from, or contribute their own.

## Structure

Skills live in domain folders at the repo root:

```
SKILLS/
├── design/
├── engineering/
├── marketing/
└── ...
```

Each domain folder contains individual skills, and each skill should have its own folder with a short `README.md` describing what it does and how to use it.

## Contributing

1. Pick the appropriate domain folder, or create a new one if your skill doesn't fit existing ones.
2. Add your skill in its own subfolder with a `README.md` covering:
   - What the skill is
   - When to use it
   - How to use / run it
3. Open a pull request.
