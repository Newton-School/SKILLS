# Contributing to SKILLS

Thanks for considering a contribution! This repo is a community collection of reusable skills, organized by domain. Anyone is welcome to add their own.

## Adding a skill

1. **Fork** the repo and create a branch off `master`.
2. **Pick a domain folder** at the repo root: `design/`, `engineering/`, `marketing/`, etc. If none fit, create a new folder — use a single lowercase word (e.g. `product`, not `product-management`).
3. **Create a folder for your skill** inside the domain folder. Use `kebab-case`: e.g. `design/figma-token-audit/`.
4. **Add a `README.md`** inside your skill folder. Copy [`SKILL_TEMPLATE.md`](./SKILL_TEMPLATE.md) and fill it in.
5. **Keep everything inside the skill folder** — scripts, assets, examples. Don't scatter files at the domain or repo root.
6. **Open a pull request.** Fill in the PR template.

## Style rules

- Folder names: lowercase, `kebab-case`, no spaces.
- One skill per folder.
- No secrets, credentials, API keys, or private data — anywhere.
- Prefer Markdown for docs; keep examples runnable and self-contained.

## Review

A maintainer will review your PR. Small, scoped PRs (one skill per PR) get merged faster. Expect light feedback on naming and the README before merge.
